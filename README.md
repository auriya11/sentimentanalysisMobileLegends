Sentiment Analysis & Web Scraping for Mobile Legends
This project includes sentiment analysis and web scraping of reviews from the Google Play Store for the game Mobile Legends.

Key Features:
1. Web Scraping – Extracts Mobile Legends reviews from Google Play Store using google-play-scraper
2. Sentiment Analysis – Utilizes NLP to determine whether reviews are positive, negative, or neutral
3. Machine Learning – Implements models like Scikit-learn, TensorFlow, and NLTK for sentiment classification
4. Data Visualization – Analyzes sentiment patterns using Matplotlib and Seaborn
